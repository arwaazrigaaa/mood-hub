# Mood Hub 

A simple mood tracker that runs in the browser. Pick how you feel, add an optional note, and watch your history and stats grow.

## Features

- Log your mood with one of 5 emojis + an optional note
- History of every entry, newest first (with delete)
- Stats: total entries, daily streak, average mood over the last 7 days
- Data is saved in your browser with `localStorage`, so nothing is lost on refresh

## Tech

- HTML
- CSS
- Vanilla JavaScript (no framework, no dependencies)

## Run it locally

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/<your-username>/mood-hub.git
cd mood-hub
open index.html   # or just double-click the file
```
